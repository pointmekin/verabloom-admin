# Edit recorded payouts

Type: task
Status: ready-for-agent

## Scope

Allow an authenticated admin to correct a payout recipient, amount, transfer date, or note after it is recorded.

## Acceptance criteria

- The existing payout form loads a selected payout for editing.
- Saving applies the same recipient, amount, date, and note validation as creation.
- The table offers a clear edit action in its mobile layout.
- Editing one record does not create a second payout record.
